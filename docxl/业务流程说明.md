# 业务流程说明

> AI 工程问题与 RAG 链路设计见 [项目说明.md](../项目说明.md) 章节 2、章节 3；本文档聚焦业务时序与交互流程。

## 1 用户注册登录

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant A as Auth API
    participant DB as MySQL

    U->>F: 输入邮箱/手机号+密码
    alt 注册
        F->>A: POST /auth/register
        A->>DB: 写入 users + 生成 user_no
    end
    alt 短信验证码登录（新用户自动注册）
        F->>A: POST /auth/send-code
        A-->>F: 验证码已发送
        F->>A: POST /auth/login (code)
        A->>DB: 校验/创建用户
    end
    F->>A: POST /auth/login (password)
    A->>DB: 校验密码（bcrypt）
    A-->>F: JWT access_token + refresh_token
    F->>F: localStorage 持久化
```

## 2 知识库上传（含多模态标准化）

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant K as Knowledge API
    participant N as DocNormalizer
    participant P as KnowledgeProcessor
    participant C as ChromaDB

    U->>F: 选择文件上传（选知识库+分块策略）
    F->>K: POST /knowledge/upload (kb_id, slice_method)
    K->>K: 保存文件 + 写 knowledge_documents (status=processing)
    K->>N: 文档标准化（PDF/DOCX→抽图→OCR/VLM→Markdown）
    N-->>K: normalized.md + manifest.json + 图片资产
    K->>P: 分块（按选定的切片策略）
    P->>C: Embedding + upsert 向量
    P->>K: 更新 status=ready, chunk_count
    F->>K: GET /knowledge 刷新列表
```

## 3 智能问答（SSE 全链路 · 含问句工程与防稀释）

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant C as Chat API
    participant P as AgentPipeline
    participant R as RAG混合检索
    participant AD as 防稀释引擎
    participant L as LLM网关
    participant FU as 追问生成
    participant DB as MySQL

    U->>F: 输入问题（可选选择知识库）
    F->>C: POST /chat/stream (SSE, kb_id)
    C->>C: 每日配额检查 (429 超限)
    C->>DB: 后台异步保存 user message
    C->>P: 问句工程 意图→改写→关键词→rag_query
    Note over P: Greedy JSON；术语表默认关闭
    C-->>F: event:meta (intent/pipeline/llm/kb_id)
    C->>R: 多路合并检索 混合粗排 阈值0.65
    alt 无达标片段
        R-->>C: 空检索
        C-->>F: 兜底话术 不调LLM
    else 有上下文
        alt 片段数 > 8
            R->>AD: 防稀释压缩
        end
        R-->>C: 文档片段 + 可选摘要
        C-->>F: event:citations
        C->>L: 流式生成（Prompt硬约束）
        loop token stream
            L-->>C: delta
            C-->>F: event:token
        end
        C->>FU: 追问建议 2-3条
        C-->>F: event:follow_ups
        C->>DB: 后台异步保存 assistant message
        C-->>F: event:done
    end
```

## 4 多知识库路由

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant KB as KB API
    participant R as 路由引擎
    participant DB as MySQL/Chroma

    U->>F: 选择/创建知识库
    F->>KB: POST /knowledge-bases （创建）
    F->>KB: GET /knowledge-bases/all （列表）
    U->>F: 上传文档到指定知识库
    F->>KB: POST /knowledge/upload (kb_id=X)
    U->>F: 提问（未指定知识库）
    F->>R: POST /knowledge-bases/auto-route?question=
    Note over R: 关键词匹配各KB文档名→评分→选最优
    R-->>F: {kb_id, kb_name, score}
    alt 首轮检索最高分 < 0.65
        F->>R: 二次选库重检
    end
    F->>F: 使用路由结果检索
```

## 5 大规模上下文防稀释流程

```mermaid
flowchart TD
    A[RAG检索结果] --> B{片段数 > 8?}
    B -->|否| C[直接使用原始片段]
    B -->|是| D[按来源文档分组 最多5组]
    D --> E[组内 score×0.6 + kw×0.4 排序]
    E --> F[提取关键规则: 编号/禁止/必须]
    F --> G[LLM生成分层摘要]
    G --> H[构建防稀释上下文]
    C --> I[Prompt硬约束 + LLM生成]
    H --> I
```

## 6 意图纠偏流程

```mermaid
sequenceDiagram
    participant F as 前端
    participant C as Chat API
    participant IS as IntentSuggest
    participant L as LLM

    F->>F: 用户点踩意图 👎
    F->>C: GET /chat/intent-alternatives (message_id)
    C->>IS: build_intent_alternatives
    IS->>IS: 内置备选 INTENT_LABELS
    IS->>L: LLM推测 1-2个候选意图
    IS-->>F: {builtin, suggested, term_hints}
    F->>F: 用户选择正确意图
    F->>C: POST /feedback (含 corrected_intent)
```

## 7 限流策略

- 每用户每日提问上限由 `daily_question_usage` 表统计
- 配置项见 `.env.example` 中 `DAILY_QUESTION_LIMIT`（默认 100）
- 超限返回 HTTP 429
- 单次提问不超过 `MAX_QUESTION_LENGTH`（默认 500 字）
- FAQ 命中直出，不走检索/大模型（`chat_faq.py`）

## 8 异常处理

| 场景 | 行为 |
|------|------|
| LLM API 失败/超时 | SSE 推送错误信息；`llm_error_recovery.py` 截断重试/换节点 |
| 知识库检索为空 | 返回 `FALLBACK_NO_CONTEXT`，**不调用大模型** |
| 向量库不可用 | RAG 降级为空 → 兜底话术，日志可观测 |
| 防稀释 LLM 失败 | 降级为原始排序结果，不阻塞主链路 |
| 预处理 JSON 失败 | 规则改写 + 关键词（`agent_pipeline.py`） |
| 未登录 | 401，前端路由守卫重定向 /login |
| 限流触发 | 429，前端提示次日再试 |
| SSE 连接中断 | 后台继续生成并异步落库 |
| Embedding 未加载 | 日志告警，BM25 词面匹配部分可用 |
